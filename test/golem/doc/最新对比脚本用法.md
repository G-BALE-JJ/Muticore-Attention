# 最新对比脚本用法

## 作用

`tests/run_latest_comparison.sh` 用于对比最近两轮实验，自动调用 `tests/stats/plot_run_comparison.py` 生成标准 comparison 图和汇总表。

默认行为：

- 从 `artifacts/stats/run_summary.csv` 中选取最新两轮 run
- 在 `artifacts/stats/analysis/comparison` 下生成对比结果

## 基本用法

在 `tests` 目录下执行：

```bash
./run_latest_comparison.sh
```

或者使用绝对路径：

```bash
/data4/lishun/pkg/sst-elements/src/sst/elements/golem/tests/run_latest_comparison.sh
```

## 指定 run

如果不想使用最新两轮，可以手工指定 base 和 opt：

```bash
./run_latest_comparison.sh \
  --base-run-id run_20260328_181824_939149 \
  --opt-run-id run_20260328_184355_956839
```

## 手工指定图例

如果旧 run 没有完整记录 feature，可以手工覆盖图例文本：

```bash
./run_latest_comparison.sh \
  --base-run-id run_20260328_181824_939149 \
  --opt-run-id run_20260328_184355_956839 \
  --base-feature-label "dirHi=25GB/s" \
  --opt-feature-label "dirHi=100GB/s"
```

这样生成的图例会更适合批量实验辨别，不再只是 `baseline/optimized`。

## 手工指定标题副标题

如果希望图标题直接说明实验变化，可以加：

```bash
./run_latest_comparison.sh \
  --base-run-id run_20260328_181824_939149 \
  --opt-run-id run_20260328_184355_956839 \
  --base-feature-label "dirHi=25GB/s" \
  --opt-feature-label "dirHi=100GB/s" \
  --title-suffix "Changed: dirHi 25GB/s -> 100GB/s"
```

## 输出位置

输出目录默认是：

`tests/artifacts/stats/analysis/comparison/<base_run>_vs_<opt_run>`

目录中通常包含：

- `comparison_summary.csv`
- `execution_comparison_*.png`
- `noc_comparison_*.png`
- `memory_comparison_*.png`
- `comparison_metadata.txt`
- `source_csv/`

## 环境变量

可选环境变量：

- `GOLEM_RUN_SUMMARY_CSV`：覆盖 `run_summary.csv` 路径
- `GOLEM_OVERLAP_ROOT`：覆盖 run stats 根目录
- `GOLEM_COMPARISON_OUT_DIR`：覆盖 comparison 输出目录

## 建议

- 新实验尽量让 `run_summary.csv` 自动记录关键 feature
- 旧实验如果缺字段，优先用 `--base-feature-label` 和 `--opt-feature-label` 补齐说明
- 批量实验时，标题副标题建议只写本次真正变化的参数，避免过长
