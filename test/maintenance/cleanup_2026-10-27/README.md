# 2026-10-27 磁盘清理

累计回收 **829,284,237,312 字节（772.33 GiB）**。
最终核对时，文件系统可用约 **1.3 TiB**，使用率 **28%**；整个 LLM 目录约 **136 GiB**。

| 操作 | 范围 | 回收磁盘空间 |
| --- | --- | ---: |
| 第一轮 | 16 组明确 FAIL 或已中断 RUNNING 的实验，删除 1,393 个 `.bin` / `.npy` | 123.48 GiB |
| 第二轮 | 12 组无数值验收结果的早期中断试跑，删除 875 个张量文件；无损压缩 116 个大日志 | 70.38 GiB |
| 历史张量退役 | 删除关键参考范围外的 23,518 个可重新生成的 `.bin` / `.npy` | 448.76 GiB |
| 历史日志归档 | 对 463 个大日志进行 Zstandard 压缩，逐份解压比对 SHA256 后删除未压缩副本 | 126.21 GiB |
| 迁移调试收尾 | 删除本次迁移失败试跑/临时调试中的 93 个张量，保留四阶段通过结果 | 3.51 GiB |

每项清理启动前没有 SST/MPI 仿真在运行。保留所有成功验收报告、当前
2026-10-24/26 prefill 配置引用的参考结果与张量、历史源码快照和安装库。
外层审计失败但内层数值验证通过的两组实验未按失败产物删除。

每轮 `protected_before.json` / `protected_after.json` 保存原两个仓库的源码哈希、
Git 状态、库哈希和成功结果报告哈希，清理后逐项一致；这些大型核对文件保留在本地。
实际删除清单见 `manifest.json`、`deleted.jsonl`、`round2/manifest.json` 与
`round2/journal.jsonl`。历史张量清单和日志压缩记录位于 `retired_history/`。
前四项结果文件 `result.json`、`round2/result.json`、`retired_history/result.json`、
`retired_history/log_result.json` 均为 PASS。迁移调试清单见 `layout_debug_cleanup.json`，结果见
`layout_debug_result.json`；最终核对见 `verification_final.json`，同样为 PASS。
大型清单留在本地，Git 只收录维护脚本和说明。

第二轮只压缩无效试跑日志，压缩后逐字节解压计算 SHA256，与原日志核对一致后才删除
未压缩副本。可用 `gzip -dk <日志.gz>` 恢复原日志。日志内容与原始时间单位均保留。
历史日志可用 `zstd -d -k <日志.zst>` 恢复，或 `zstd -dc <日志.zst>` 读取。
日志归档保留原始内容及时间单位；直接读取旧 `.log` 路径的分析脚本需要先解压。

历史张量退役保留了 15 处关键参考范围，包括当前两份 prefill 选择引用的完整用例、
早期正式 prefill、FP16 端到端、checkpoint 导入及 GPU handoff 等目录。
硬链接张量和源码/安装快照不在删除范围内。部分保留目录原本就没有张量。
**历史成功实验也可能只保留报告和配置，已退役张量需重新生成后才能再次做数值复核。**
这次清理不代表重新执行或重新验收了历史实验。

历史数据整理至 `LLM/test/history/`。旧目录路径通过兼容链接访问，因此清单中
原绝对路径仍可定位相应实验目录。新增公共工作区、构建准备及通过的验证产物
不计入上述回收量；文件系统可用空间会随后续运行变化。
