# LLM prefill 部署进度：2026-10-14

当前已完成 `token IDs → 架构内 Embedding → 两层 Decoder → final RMSNorm → 最后 token 的 LM head → host greedy argmax`，并完成通用 GEMM 输出 panel、预取及首个分块融合。最新正式 rank=8 端到端为 **10,210,612.75 cycles**，较优化前归档减少 **49.37%**，所有层输出和 logits 逐位一致。此文是当前状态入口；此前各阶段报告保留各自历史计时口径。

## 最新数据流优化

- Wo 正式规模同 binary/library 对照：Attention O ACK → Wo ACK 从 660,544.5 降到 459,999.5 cycles，减少 30.36%。
- panel 覆盖 Wo/gate/up/down，输出请求从 128 B 串行改为最多 2 KiB、最多 8 个在途；两个 128 KiB GM panel 等全部 ACK 后复用。
- 两份 8 KiB 权重预取槽与当前 tile 编程/计算重叠；保留单 operand bank 和原 GM/NoC/HBM 资源参数。
- 融合最多 8192 元素的 SiLU × up，保留真实共享 SFU 流水线和中间 FP16 舍入，正式两层少 64 MiB HBM 往返。gate/up 和 down 尚未整体融合。
- 最新正式 panel-only 为 15,453,844.75 cycles；同 binary/library 的预取与融合进一步减少 33.93%。四组小规模 A/B 分别验证每一步，完整优化减少 40.89%。
- 回归检查共 279 项通过；正式 panel/fused 的 576/544 个 job 通过 DMA 字节与完成时序资源核对。

详见 [实现与验证报告](DECODER_DATAFLOW_2026-10-14.md)，以及 [正式对照](progress_results/2026-10-14/decoder_dataflow_formal.json)。下面的 4/8 MPI 结果为优化前归档；最新两组正式仿真曾并发运行，不用于推断独立运行的 wall 加速比。

## 已实现功能

- 每层完整执行 RMSNorm1、Q/K/V 投影、RoPE、causal GQA Attention、Wo、第一残差、RMSNorm2、SwiGLU FFN（gate/up、SiLU、逐元素乘法、down）和第二残差。
- 两层使用独立权重和共享 scratch，统一 C++ 内存布局管理偏移，activation ping-pong；复用时检查 epoch、completion flag reset、DMA ACK 和资源退役。
- 增加独立 final RMSNorm 和最后一个 token 的 LM head；支持 M=1、非整组尾行以及 N≤8192 的词表分块，填充列不参与 token 选择。
- Embedding 为 worker 定时 gather：HBM token ID 读入 GM，查跨四节点分片的 FP16 表，GM→HBM 写回第一层输入；无需 host 预载查表后的 activation。
- 基础加法、乘法和 SiLU 接入 SFU 定时流水线；SiLU 逐批使用共享 EXP、倒数等资源。保留既有 FP16 I/O 和 FP32 norm 内部计算。
- host argmax 返回有效词表的 greedy token ID，并与局部 CPU 参考核对。最高 logit 并列时取最小 token ID。
- 配置支持每个数据 HBM node 2 GiB，guest stride、SST 地址范围和 backing 同步；容量扩展未改变带宽。worker GM 2 MiB、WCP C-buffer 1 MiB。
- 增加 Attention query-block 的 8 MPI rank 分区：每列 QK 与 PV 分到一对 rank，硬件仍为 4 managers + 16 workers，每 worker 64 arrays。

## 复现

先按仓库现有安装流程构建并安装修改后的 SST elements library，再执行：

```bash
source scripts/env_local_install.sh
make -C src/sst/elements/golem/tests/small/muticore_attention decoder-embedding
python3 baseline/attention_cluster_8qk_8pv/run_decoder_stack.py --embedding \
  --shape formal --mpi-ranks 8 --artifact-root results/embedding_NEW/formal_rank8
python3 baseline/attention_cluster_8qk_8pv/run_decoder_stack.py --embedding \
  --shape formal --mpi-ranks 4 --artifact-root results/embedding_NEW/formal_rank4
python3 baseline/attention_cluster_8qk_8pv/summarize_embedding_token.py \
  --artifact-root results/embedding_NEW
```

具体数据路径与检查见 [Embedding/token/MPI](EMBEDDING_TOKEN_MPI_2026-10-14.md)、[两层同步与布局](DECODER_STACK_2026-10-14.md)、[final RMSNorm](FINAL_RMSNORM_2026-10-14.md)、[LM head](LM_HEAD_2026-10-14.md)和 [SFU 向量流水线](SFU_VECTOR_PIPELINE_2026-10-14.md)。
