## P1 与局部筛选证据

## 错误 ACK 根因修复

新增真实 Wo 失败 ACK 回归在候选上发现 `std::bad_function_call`：同一窗口有多个在途 A 预取，首个失败已移动完成回调，但 tick 仍继续发送其他槽请求；后续失败再次调用空回调。

修复位于 `reuseWindowGemm.h`：完成仅触发一次；各泵送阶段在窗口失活后立即停止发新请求。`DecoderOpJob` 保持失败直读 lease，并拒绝在 retire 后启动任何会覆盖 landing 的新作业。
最初失败日志与修复后的同步/延迟 ACK 日志均保留于实验目录。该修复不改变成功路径的模拟时钟推进。
扩展生产路径回归初轮 174 项通过；源码定稿后的完整生产路径套件 175 项通过，Python 套件 246 项通过。

## P6 final RMSNorm -> LM 软件流式交接（2026-10-24）

候选开关为 `--final-norm-lm-stream`。每个 worker 完成本地 final RMSNorm 后，使用现有 HBM flag wait 指令等待最后有效 token 所属 worker 的 final Norm 完成 epoch，再提交本地 LM vocabulary chunks。所有 vocabulary shards 消费同一个 token，不能仅依赖自己的 Norm 完成。manager 在最后一层 decoder release 前清零 LM 完成标志，避免覆盖提前完成的 LM epoch；随后只等待最终 LM epoch，不广播全局 `lm_head_release`。

本轮修复了开关未进入模拟 guest 环境白名单、LM done 标志清零时序以及最后 token 的跨 worker 依赖。默认路径仍使用原全局 release。同一 guest 二进制配对运行，只有该软件开关不同。没有新增硬件组件、descriptor 类型或 HBM/GM 资源；FP16 final output 仍写入既有 HBM，LM 从同一地址读取。

测试新增了全部 1024 个逻辑 token 的 producer flag 映射、guest 环境转发以及性能配对拒绝条件。guest 调度/融合回归 12/12、比较脚本回归 8/8 通过。比较器检查相同输入、源码哈希、guest/SST 库、硬件环境、dense MAC/A/B/C 流量和最终 Y/Norm/logits 逐位一致；源码临时目录名和宿主绑核位置仅作规范化，不隐藏文件内容差异。

正式配对目录为 `results/optimization_20261024/p6_pair_v2_{control,stream}/reuse_window_probe/`，规模 S1024/H2048/FFN8192、两层、vocab128256、MPI8。完整 SST 及离线数值/资源验收均已完成。原小规模停滞 smoke 和中止的首版 control 均不是可用的性能证据。

## P7：恢复默认周期与生产者通知（已完成）

默认 runtime 去除 P6 的启动期 getenv/分支，实验代码由 `GOLEM_DECODER_TAIL_EXPERIMENT` 编译隔离。重建默认 embedding guest 的 SHA-256 为 `7ee4f229860f8c83dea431a72f10cbcf58e02d6de4bb76c454807e95f067f57c`，与历史 p4_scoped_control 完全一致；默认 guest 环境不再增加 stream/priority 两个键。库、硬件架构、容量、端口均未改动。

新 `decoder-embedding-tail` / `decoder-lm-head-tail` 使用相同实验二进制，以运行时 flag 配对。stream-off、notification、producer-first 均在最后一层 decoder release 前清零 LM flags，作为共同准备，避免把 reset 搬移作为通知收益。worker 只在自己的 decoder 完成后读取实验选项。真正 token producer 完成 Norm 输出与 completion ACK 后，设置本地 release，再通过现有 remote_store 向另外 15 个 worker 发送 8-byte 通知；各 worker 轮询自己的 GM release，不读 HBM flags。manager 继续核对所有 Norm 和 LM 完成。新增 header 仅封装 guest 软件顺序，无新 descriptor 类型、硬件模块或缓冲容量。

`--final-norm-producer-first` 是独立粗粒度实验：先执行最后 token 所属的整个 64 行 Norm 作业，其余 Norm worker 在通知后执行自己的 Norm，再做 LM。不省略、不重复任何行；它没有消除 Norm→LM 张量 HBM IO，也不宣称实现了 row-level fusion。
